We're re-planning the channels on our train radio network and I need a planner that gets the total interference penalty as low as it will go. The drive test survey for the line is in `/app/survey`, and the README there explains the files, the rules a plan has to follow and how its penalty adds up.

It has to be C++ with only the standard library, in `/app/planner/src` (there's a stub, keep `planner.cpp`). For grading we drop everything in `/app/planner` except the .cpp and header files sitting directly in src, compile every .cpp there with `g++ -O2 -std=c++17`, and run the binary from `/app/planner` with two arguments, the survey directory and the path to write the plan to. The plan is a csv with the header `radio,channel` and one row for each radio in the survey. Each run gets 60 seconds of wall time, and a run still going at 60 seconds is killed and fails. While it runs it can't start other programs, and the box's interpreters and shell tools are closed to it.

We know the lowest penalty any legal plan can reach on this survey. Yours has to be legal and come in no more than 0.75% above that. The same binary also gets run on a second survey you haven't seen, same files and format: a longer line with up to 500 masts, 7 channels on the licence instead of 6, and its own penalties and barred channels. It has to be legal there too and within 0.75% of that survey's lowest. Leave the files in `/app/survey` as they are, we check them.
